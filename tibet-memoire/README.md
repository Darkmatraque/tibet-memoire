# Tibet — Mémoire & Culture

Site web statique en français consacré à l'histoire, au patrimoine et aux épreuves du Tibet.

## Fichiers
- `index.html` — contenu et structure
- `style.css` — design responsive, mode clair/sombre
- `script.js` — thème, navigation mobile et animations

## GitHub Pages
1. Dépose les fichiers à la racine du dépôt GitHub.
2. Va dans **Settings → Pages**.
3. Dans **Build and deployment**, choisis **Deploy from a branch**.
4. Sélectionne `main` et `/ (root)`, puis **Save**.

Le bouton de don pointe vers la page officielle « Support Tibet » de l'International Campaign for Tibet : https://savetibet.org/support-tibet/

## Images
Les images de démonstration utilisent des URLs Unsplash afin que le projet reste léger. Pour une version finale, il est recommandé de remplacer ces images par des photos dont tu possèdes les droits ou dont la licence autorise l'utilisation.
