## GitHub Pages
Déposer tous les fichiers directement à la racine du dépôt, puis :
Settings → Pages → Deploy from a branch → main → / (root).

## Remarque
Les photos de démonstration utilisent des URLs Unsplash. Pour une publication finale, remplacer les images par des visuels dont l'utilisation est autorisée.
Les liens documentaires externes sont indiqués dans les pages. Le lien de don renvoie vers la page officielle de l'International Campaign for Tibet.
